# Typing Coach

文章タイピングを主軸に、練習履歴を自動保存・分析するWebタイピングツールです。

## 実装済み

- 文章 / 長文 / 単語集中
- 60秒 / 120秒 / 5分 / エンドレス / 1文章
- 入力欄を使わないタイピングサイト型UI
- 正しく打った文字の色変化
- 現在文字の強調、誤入力フィードバック
- 最初のキー入力から計測
- WPM / 正確率 / ミス / 経過時間
- 練習履歴の自動保存
- キー別・2文字連続の弱点分析
- 弱点に応じた問題の自動選択
- 自動コーチ
- 成長グラフ
- CSV出力
- JSONバックアップ / 復元
- ChatGPT分析用データのコピー
- 集中モード
- 目標WPM設定

## データ保存

履歴はブラウザの localStorage に保存します。
ブラウザデータを削除すると履歴も消えるため、必要に応じてJSONバックアップを利用してください。
